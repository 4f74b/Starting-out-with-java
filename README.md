# 🚀 Starting Out with Java

Welcome to **Starting Out with Java**, your one-stop repository for mastering Java programming! Whether you're a beginner diving into the world of coding or an intermediate learner exploring Spring Boot, this project is packed with resources to fuel your Java journey. From practice code to comprehensive notes and a full textbook, we've got you covered!

## 📚 What's Inside?

This repository is structured to support your learning with hands-on code, reference materials, and Spring Boot resources:

- **📖 Book**: 
  - Contains the *Starting Out With Java* textbook in PDF format (`book/Starting-Out-With-Java.pdf`). Your go-to guide for Java fundamentals, from variables to object-oriented programming.

- **💻 Sample Codes**:
  - A collection of Java practice codes (`sample-codes/`) to reinforce your understanding. Perfect for experimenting with loops, arrays, classes, and more.

- **🌱 Spring Boot**:
  - **Learning Material**: Detailed notes in `Spring Boot/learning material/Notes.docx` covering Spring Boot concepts like dependency injection, REST APIs, and more.
  - **Implements**: Practical Spring Boot code examples (`Spring Boot/Implements/`) to help you build real-world applications.

## 🎯 Why This Repository?

- **Beginner-Friendly**: Start with basic Java concepts and progress at your own pace.
- **Hands-On Learning**: Practice with sample codes and Spring Boot projects to solidify your skills.
- **Comprehensive Resources**: Combine textbook theory with practical notes and code for a well-rounded learning experience.
